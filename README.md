# MathBook

Простий сайт для класу з математики: тренажери, уроки, бали (XP), рівні й рейтинг.

- **Сайт** — файл `index.html`, лежить на GitHub Pages (безкоштовно).
- **База даних** — Google Таблиця: учні, тренажери, уроки, результати.
- **Сервер** — Google Apps Script (`apps-script/Code.gs`), з'єднує сайт і таблицю.

Відкрийте `index.html` у браузері — він працює в демо-режимі (вхід: «Оля К.», PIN `1234`, або «Спробувати як гість»), поки не підключена таблиця.

---

## Крок 1. Google Таблиця і скрипт

1. Створіть нову Google Таблицю (наприклад, «MathBook 5-А»).
2. Меню **Розширення → Apps Script**.
3. Видаліть усе у файлі `Code.gs` і вставте вміст файлу `apps-script/Code.gs` з цього проєкту. Натисніть 💾 **Зберегти**.
4. Угорі виберіть функцію **setup** і натисніть **Виконати**.
   Google попросить дозвіл — дозвольте (це ваш власний скрипт; «Додатково → Перейти до проєкту»).
5. Поверніться в таблицю — з'явились аркуші: *Налаштування, Учні, Тренажери, Уроки, Результати* з прикладами.

## Крок 2. Опублікувати скрипт як веб-застосунок

1. В Apps Script: **Розгорнути → Нове розгортання**.
2. Тип (⚙️) — **Веб-застосунок**.
3. *Виконувати як* — **Я**. *Хто має доступ* — **Усі**.
4. **Розгорнути** → скопіюйте **URL веб-застосунку** (закінчується на `/exec`).

> Після кожної зміни коду скрипта: **Розгорнути → Керувати розгортаннями → ✏️ → Версія: нова → Розгорнути**. Адреса залишиться та сама. Зміни в самій таблиці (нові учні, питання) видно одразу, без перерозгортання.

## Крок 3. Підключити сайт до таблиці

Відкрийте `index.html` і на початку скрипта вставте адресу:

```js
const API_URL = 'https://script.google.com/macros/s/.../exec';
```

## Крок 4. Опублікувати на GitHub Pages

1. На github.com: **New repository**, назва, наприклад, `mathbook`, тип **Public**.
2. **Add file → Upload files** → завантажте `index.html` → **Commit changes**.
3. **Settings → Pages** → *Source*: **Deploy from a branch**, *Branch*: **main**, папка **/(root)** → **Save**.
4. За хвилину-дві сайт буде за адресою `https://ВАШ-ЛОГІН.github.io/mathbook/`. Цим посиланням і діліться з учнями.

## Як вести клас у таблиці

| Аркуш | Що робити |
|---|---|
| **Налаштування** | Назва класу, скільки XP за правильну відповідь і чи ввімкнено гостьовий режим (`так` / `ні`). |
| **Учні** | Ім'я та PIN кожного учня. PIN роздайте особисто (на папірці). |
| **Тренажери** | Один рядок — одне питання. Рядки з однаковою назвою в колонці «Тренажер» складають один тренажер. Якщо заповнити «Хибні варіанти» через кому — питання стане тестом із вибором. |
| **Уроки** | Один рядок — один крок: пояснення + питання. Учень не піде далі, поки не відповість правильно. |
| **Результати** | Заповнюється автоматично: хто, коли, що пройшов, скільки XP. Звідси рахується рейтинг. Можна сортувати, фільтрувати, будувати графіки. |

**Підказки до відповідей:**
- Числа порівнюються розумно: `0,5`, `0.5` і `1/2` — однакові.
- Кілька правильних варіантів пишіть через `|`, наприклад: `y|вісь y`.

**Рівні:** Новачок (0 XP) → Учень (100) → Знавець (300) → Майстер (600) → Експерт (1000) → Піфагор (1500). Змінити можна в `index.html`, масив `LEVELS`.

## Кабінет вчителя

На сторінці входу натисніть **«Я вчитель»** і введіть пароль з аркуша *Налаштування* (рядок «Пароль вчителя»).
**Обов'язково змініть пароль `змініть-мене`** — у таблиці або в кабінеті на вкладці «Налаштування».

| Вкладка | Що можна |
|---|---|
| **Огляд** | Скільки учнів займалося сьогодні, точність класу, таблиця учнів (XP, рівень, спроби, точність). Натисніть на учня — побачите його історію. Блок «Найважчі теми» показує, де клас помиляється найчастіше. |
| **Учні** | Додати учня (PIN згенерується сам або впишіть свій), видалити, показати PIN-коди, щоб роздати. |
| **Тренажери** | Створити тренажер прямо на сайті або видалити. Уроки поки редагуються в таблиці. |
| **Налаштування** | Назва класу, XP за відповідь, гостьовий режим, новий пароль. |

Усе, що ви змінюєте в кабінеті, записується в ту саму Google Таблицю.

### Оновлення скрипта (якщо таблиця вже створена)

1. В Apps Script замініть код у `Code.gs` на новий з цього репозиторію і збережіть.
2. Ще раз запустіть **setup** — він нічого не стирає, лише додасть рядок «Пароль вчителя» і переведе аркуші з відповідями в текстовий формат (щоб `3/8` не перетворювалось на дату).
3. **Розгорнути → Керувати розгортаннями → ✏️ → Версія: Нова версія → Розгорнути.** Адреса `/exec` лишиться та сама.

## Режим гостя

На сторінці входу є кнопка **«Спробувати як гість»**: без імені та PIN можна проходити тренажери й уроки, бачити рейтинг.
Бали гостя зберігаються лише в його браузері й **не записуються** в таблицю та рейтинг.
Зручно для батьків, нових учнів або щоб показати сайт колегам. Вимкнути: на аркуші *Налаштування* напишіть `ні` навпроти «Гостьовий режим».

## Про безпеку

- PIN-коди перевіряє скрипт; сайт їх ніколи не отримує.
- Таблиця залишається приватною — доступ до неї маєте лише ви.
- Не записуйте в таблицю зайвих персональних даних: досить імені та першої літери прізвища.
